# projeto2wlstore


Desenvolvimento do Projeto 2WLSTORE
1. Introdução
O presente trabalho tem como objetivo apresentar o desenvolvimento e o funcionamento do aplicativo 2WLSTORE, projeto realizado pelo grupo formado por Will, Jhulya e Conrado. A proposta do projeto é desenvolver uma aplicação que possibilite ao usuário criar uma conta, realizar o acesso ao sistema e acompanhar seus pedidos de maneira simples e organizada.
Durante a apresentação, foram demonstradas as principais etapas para utilização do aplicativo, desde o cadastro de um novo usuário até o acesso à área destinada aos pedidos.
2. Objetivo do Projeto
O principal objetivo do projeto é desenvolver e apresentar o aplicativo 2WLSTORE, demonstrando sua estrutura e o fluxo básico de utilização pelo usuário.
A aplicação foi pensada para proporcionar uma experiência simples e direta. Dessa forma, o usuário pode realizar seu cadastro, efetuar o login e, após entrar no sistema, acessar a área de “Meus Pedidos”.
A proposta busca facilitar a utilização do sistema, tornando o processo de acesso mais rápido e organizado.
3. Funcionamento do 2WLSTORE
O funcionamento do aplicativo começa pela tela inicial, na qual o usuário pode escolher entre realizar o login ou criar uma nova conta.
Caso o usuário já possua uma conta, ele deve acessar a opção de login e informar seu e-mail e senha. Após o preenchimento dos dados, o sistema permite que o usuário faça seu acesso.
Para os usuários que ainda não possuem uma conta, existe a opção de realizar um novo cadastro. Nesse processo, o usuário deve preencher os campos solicitados, incluindo e-mail e senha, e confirmar a senha para concluir o registro.
Dessa forma, o sistema apresenta dois caminhos principais: o acesso de usuários que já possuem cadastro e o registro de novos usuários.
4. Cadastro de Usuário
O cadastro é uma das etapas fundamentais para utilizar o sistema. Para criar uma nova conta, o usuário deve acessar a opção “Registre agora” e preencher os campos necessários.
Entre as informações apresentadas no projeto estão o e-mail, a senha e a confirmação da senha. Após o preenchimento dessas informações, o usuário pode concluir seu cadastro e passar a ter acesso ao sistema.
Essa etapa permite que novos usuários sejam registrados antes de utilizarem as funcionalidades disponíveis no aplicativo.
5. Login no Sistema
Depois de possuir uma conta cadastrada, o usuário pode acessar o sistema por meio da tela de login.
Para realizar o acesso, são solicitados o e-mail e a senha cadastrados anteriormente. Após informar corretamente esses dados, o usuário pode selecionar a opção “Fazer Login”.
A tela de login também apresenta a alternativa para usuários que ainda não possuem uma conta, direcionando-os para a opção de cadastro.
6. Tela de Boas-Vindas
Após realizar o acesso, o usuário é direcionado para uma tela de boas-vindas. Nessa etapa, o aplicativo apresenta uma mensagem de recepção e permite que o usuário prossiga para a área de “Meus Pedidos”.
A tela de boas-vindas funciona como uma transição entre o processo de autenticação e o acesso às funcionalidades disponíveis no sistema.
7. Experiência do Usuário
Um dos pontos apresentados no projeto é a preocupação com a simplicidade e a facilidade de utilização. O aplicativo é apresentado como uma solução que busca oferecer um acesso rápido e direto.
O fluxo de utilização é composto por etapas simples: o usuário realiza seu cadastro caso ainda não possua uma conta, efetua o login utilizando e-mail e senha e, após o acesso, pode chegar à área de seus pedidos.
Essa organização contribui para tornar a navegação mais compreensível, principalmente para usuários que estão utilizando o sistema pela primeira vez.
8. Situação Atual do Projeto
De acordo com a apresentação, o aplicativo ainda não está funcional no momento. O projeto encontra-se em desenvolvimento e a proposta é solucionar os pontos necessários para que o sistema possa funcionar corretamente.
Assim, a apresentação demonstra principalmente a estrutura planejada para o aplicativo, seu fluxo de acesso e as telas relacionadas ao cadastro, login e área de pedidos.
9. Conclusão
O desenvolvimento do 2WLSTORE representa a criação de uma aplicação com um fluxo de acesso organizado e voltado para a facilidade de utilização. O projeto apresenta as etapas de cadastro, login e acesso à área de pedidos, formando a estrutura básica de interação entre o usuário e o sistema.
Apesar de ainda não estar funcional, o projeto demonstra uma estrutura definida e uma proposta clara de funcionamento. Como próximos passos, será necessário concluir a implementação das funcionalidades apresentadas, permitindo que o usuário possa efetivamente realizar seu cadastro, acessar o sistema e utilizar a área de pedidos.
Portanto, o 2WLSTORE apresenta uma proposta de aplicação simples e objetiva, com foco em proporcionar ao usuário uma experiência de acesso prática e organizada.
