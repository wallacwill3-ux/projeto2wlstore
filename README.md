# projeto2wlstore

Desenvolvimento do Projeto 2WLSTORE

## 1. Introdução
O presente trabalho tem como objetivo apresentar o desenvolvimento e o funcionamento do aplicativo 2WLSTORE, projeto realizado pelo grupo formado por Will, Jhulya e Conrado. A proposta do projeto é desenvolver uma aplicação que possibilite ao usuário criar uma conta, realizar o acesso ao sistema e acompanhar seus pedidos de maneira simples e organizada.

## 2. Objetivo do Projeto
O principal objetivo do projeto é desenvolver e apresentar o aplicativo 2WLSTORE, demonstrando sua estrutura e o fluxo básico de utilização pelo usuário.

## 3. Funcionamento do 2WLSTORE
O funcionamento do aplicativo começa pela tela inicial, na qual o usuário pode escolher entre realizar o login ou criar uma nova conta. Após o acesso, o usuário pode acessar a área de Meus Pedidos.

## 4. Cadastro de Usuário
O usuário pode criar uma nova conta informando e-mail e senha.

## 5. Login no Sistema
O usuário cadastrado pode acessar o sistema utilizando e-mail e senha.

## 6. Tela de Boas-Vindas
Após realizar o acesso, o usuário é direcionado para uma tela de boas-vindas e pode acessar a área de Meus Pedidos.

## 7. Experiência do Usuário
A aplicação busca oferecer uma navegação simples, direta e organizada.

## 8. Situação Atual do Projeto
O projeto encontra-se em desenvolvimento.

## 9. Conclusão
O 2WLSTORE apresenta uma proposta de aplicação simples e objetiva, com foco em cadastro, login e acompanhamento de pedidos.
